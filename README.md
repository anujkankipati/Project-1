# Project 1 Personal Website

This project is my personal website for CSCE 331 at Texas A&M University.

The website includes a home page that introduces me and my interests in computer science. It also includes a portfolio page that shows a project I have completed and a project I would like to work on in the future. The qualifications page includes my technical skills and my resume. The activities page talks about some of my interests outside of computer science. The sandbox page is an AI generated space mission dashboard with interactive features.

The website was built using HTML CSS and JavaScript. My first design uses a dark background with purple colors. I wanted the website to look simple professional and easy to navigate.

## AI Prompt History

The first prompt I used was:

Create a HTML page called sandbox.html that displays a futuristic space mission dashboard. Make sure to only use HTML, inline CSS, and JavaScript. I want to have a title, mission information, several status cards, and a button that performs an interactive action within the file.

The second prompt I used was:

Can you improve the futuristic space mission dashboard. I want to add animated progress bars for fuel, oxygen, and power, a live mission timer, interactive system controls, a mission log that records button actions, and a more detailed dashboard layout. Please make sure to keep everything in one HTML file using inline CSS and JavaScript.

The third prompt I used was:

Add an interactive asteroid defense system to the space mission dashboard. The asteroids should randomly fly across a space area and I want the user to be able to click them to destroy them. Make sure to add a score counter, shield health, a start button, and a game-over state if too many asteroids get through. Keep the existing mission dashboard, timer, resource bars, mission controls, and mission log.
