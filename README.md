# Project 1 Personal Website

This project is my personal website for CSCE 331 at Texas A&M University.

The website includes a home page. It also has a portfolio page. There is a qualifications page with my resume. There is an activities page about my interests. The sandbox page includes an interactive space mission dashboard.

The website was built using HTML CSS and JavaScript.

My first design uses a dark theme with purple colors. I wanted the website to look simple and professional.

The portfolio includes a website I worked on for Alamo Liver Institute. It also includes a future project idea for an email triage system.

The sandbox page was created with help from AI prompts. It includes a mission timer. It has system controls. It also has an asteroid defense game.

The website is hosted through Texas A&M People.
